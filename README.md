Guesthouse Website – Web Development Project

This project was developed as part of my Web Development course during my semester.

The website is designed for a family-run guesthouse and includes:
- Responsive frontend using HTML, CSS, and JavaScript
- Booking form with PHP backend
- Basic SQL database integration for storing bookings
- Simple UI/UX focused on clarity and ease of use

Note: The project is currently not hosted and was built for learning and academic purposes.
